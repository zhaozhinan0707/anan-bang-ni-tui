# GLM-4V 图片提示词反推

## 执行流程

1. 先完整观察图片，再在内部判断类别。不要向用户展示分类、分析步骤或观察清单。
2. 根据画面主体和用途选择模板：
   - **A 真实场景摄影**：可见真实人物、真实环境或摄影成像特征，主体为人物与自行车、电动自行车、滑板车等车辆的互动。
   - **B 三维产品渲染**：主体呈现建模、材质着色、棚景合成、抽象数字环境或明显 C4D/Blender/Octane/Redshift 视觉特征。
   - **C 活动 banner / 促销海报**：画面以促销文案、活动主题、日期、优惠信息或按钮与产品组合为主的商业活动视觉；即使产品本身是三维渲染，也优先按 C 处理。
3. 混合画面按决定主体、空间和光线的主要制作逻辑选择；无法可靠判断时，不声明软件或媒介，只描述可见效果，并采用最接近的模板。按参考图忠实反推时，不擅自删改其关键构图；只有用户明确提出简洁化时，才按其风格偏好收敛装饰和视觉效果。
4. 按选定模板组织信息，去重并压缩：A/B 通常约 800–1200 字；C 使用单段提示词，通常约 700–1000 字；保持与 A/B 相近的信息覆盖度，只压缩装饰和冗余，不省略构图、产品关系、空间层次与光线控制。信息不足时允许更短，不编造或重复。
5. 最终只输出一整段中文生图提示词，不加标题、类别标签、前言、解释、项目符号、Markdown 围栏或追问。

## 总控规则

- 只写可观察到或可由画面合理判断的信息；不猜品牌、型号、地点、人物身份或不可见结构。
- 不确定参数使用“约”“类似”“呈现……视觉效果”等表达，不把推测写成精确事实。
- 优先写决定相似度的视觉关系，再写局部细节；同一特征只写一次。
- 使用具体视觉描述，避免机械堆叠“8K、杰作、超高清、电影感、胶片感”等空泛词。
- 不默认套用浅景深、广角、电影感或胶片感；只有图中存在明确证据时才写。
- 方向以画面中的左、右、上、下为准。涉及手脚、车把、脚踏与遮挡时，逐项核对。
- 先判断整组与局部物件是落地、悬浮、悬挂还是相互承托；保留参考的裁切和展开状态，不为追求真实而强加地面、台面或落地阴影。
- 简单画面的相似度依赖结构与材质：分清配件所属、连接、前后遮挡，以及相邻材质的纹理尺度、厚度和光泽。织带、提带和飘带优先保持自然舒展的走势；先保留结构连接或主题形状，再概括整体方向，避免逐段规定弯折造成僵硬或抢眼回环。活动图详见参考中的“悬浮、材质与带状元素”。
- 段尾自然融入一句核心锁定与一句针对性负面约束，不另起标题。

## A：人物与车辆真实场景摄影

**第一要义：自然、真实的原生拍摄感。** 人车摄影默认保留生活现场轻微的不完美和粗粝感：松弛的动作、不完全对称的姿态、自然发丝与衣物褶皱、普通环境和真实曝光层次。人物、车辆和背景不应同时被修饰得过于精致。原生感优先通过取景、动作、光线和材质体现；不靠叠加颗粒、脏污、刮痕、夸张毛孔或做旧滤镜制造。具体镜头、构图与光照仍依照当前参考，不能把本次中远景或秋日色调套用于所有人车图；用户明确指定其他摄影风格时按其要求调整。

按优先级提取并整合：

1. **摄影类型与气质**：先描述真实生活中被拍到的场景与情绪，再根据证据说明 Lifestyle、街头、纪实、出行等摄影类型。即使用于商业营销，也不默认叠加“精致高级、电影级、精修广告、柔美光泽”等容易推向过度修饰的词。
2. **机位、焦段与透视**：描述相机相对主体的高度、俯仰、方向与距离，再判断广角、标准或长焦透视感，参数只作近似。保留参考中的取景距离、主体占比、人车间距和环境留白，不能为突出车辆而拉近镜头、放大人物与车辆或把画幅挤满。
3. **构图与空间层次**：说明人物和车辆的位置、朝向、裁切及前中后景关系。用距离、透视和遮挡保留现场空间；不凭空增加景物营造纵深，不将自然街景摆成整齐的影棚陈列。
4. **人物、面部与车辆**：人物只写可见的年龄段、外观、发型、服装、表情、视线与动作，保留自然的不对称和互动瞬间，不强制所有人正对镜头微笑。面部要求自然肤色、细微肤质与柔和受光，额头、鼻梁和面颊的高光小而克制；避免油亮脸、湿润反光、蜡质皮肤、塑料感、过度磨皮、美颜妆感、强锐化毛孔和过分雕琢的表情，也不为真实感刻意丑化或加重皱纹。车辆先描述整体轮廓、比例和关键结构，保留可见的哑光、软膜自然折痕等材质，不将其自动美化为崭新光亮的棚拍产品。
5. **人车关系**：这是最高优先的结构细节。明确人物在车内、车外、车上或车旁，哪只手接触何处、哪只脚落地或踩踏、身体相对车辆的位置与遮挡。人与人互动也保留拥抱、倚靠和视线关系，只写可见动作，不擅自安排骑行、触车或额外互动。
6. **场景与细节密度**：保留道路、住宅、墙窗等实际环境及其朴素的大块面，纹理清楚但对比克制；不擅自添加花丛、盆栽、装饰灯、宠物或密集落叶。真实的不规整不等于全画面细碎凌乱，细节集中于主体识别和必要现场线索。
7. **光线与色调**：把色彩关系作为摄影风格的核心，按背景、主体、强调色，以及亮部、中间调、暗部分别判断色相、饱和度、亮度、所占面积与过渡；区分整体明暗对比和局部纹理的微对比，不能只用“暖色、胶片感、暗部厚重”概括。依参考判断日光、漫射、侧光或逆光，保留真实曝光关系，不用美容补光抹平面部。低饱和高亮度的环境仍可搭配深色主体和少量鲜明强调色，不等于全图提亮、褪黑或去色；这也是条件性判断，不能套用到所有摄影图。控制树影及反射密度，保留中性色和自然肤色，不自动把环境染成浓橙棕或强化戏剧化对比。
8. **景深、运动与成像**：按参考判断清晰度分布，不把主体清晰或零件可辨设为硬要求。速度型、慢快门或有镜头晃动的照片，允许头盔、肢体、车架和轮组明显模糊、重影及损失细节，优先保留动作、色块和运动痕迹。分别观察主体与背景的拖影方向、长度、直线或弯曲走势、边缘叠合及区域差异；二者可能方向不同，不能统一写成“斜向运动模糊”。区分车辆行进方向、画面中可见拖影的方向与相机运动推测；单张照片不足以证明完整相机轨迹或精确快门参数时，只锁定可见效果。不要把全局晃动改成清晰主体加模糊背景，也不用均匀柔焦、浅景深或人工速度线替代方向性拖影。参考中细节已融合成宽缓色带时，降低土粒、胎纹、服装图案等局部微对比，不额外增加泥污、刮痕和颗粒来制造粗粝感。
9. **核心锁定与负面约束**：锁定取景距离、机位、主体占比、人车动作、车辆朝向、空间留白与自然光。针对性限制肢体错位、错误接触、车辆变形及本次最可能的风格偏差，如摆拍感、过度精修、油亮面部、密集碎光、背景添景、过度 HDR 或 CG 感，避免堆砌无关限制。

当参考的主要表现力来自速度、晃动或调色时，输出顺序优先写“机位与人车姿态 → 主体/背景各自的运动成像 → 分区域色彩与明暗 → 必要外观细节”。保留迎面或侧向的透视、车身倾斜和骑手姿态差异，不为清楚展示零件把人车改成规整侧面。首尾约束保持一致：前面要求主体模糊，后面就不能再要求脸部、轮胎或全车锐利清晰。

### 极强残影与动静对比（按参考或用户要求启用）

- **先锁定清晰度角色与作用范围**：区分相对静止的人物、静止环境和高速经过的区域；同一主体内部也可按参考划分稳定区与曝光拉伸区。清晰度、身份或肤质保留要求仅作用于指定稳定区，不能覆盖需消融的部分；交代两区自然渐变的边界，避免机械劈半。不要把这种局部动静对比套用于整幅晃动照片，也不要默认所有运动场景都必须抽象化。
- **描述成像结果，减少结构词重复**：当目标是看不清来源的残影，优先写可见的色块、拖曳轴向、覆盖范围、宽窄变化、浓淡、透明度、断续与边缘消散。核心措辞可用“原始位置不留下清晰核心，内部细节融合，不保留完整可识别剪影”。不反复列举头盔、车轮等零件，否定句也避免逐项重提；不断增加“极快、极强”不能代替可观察的结果描述。此方法是本次迭代有效的写法，不据此断言特定模型内部机制。
- **明确形体在曝光中如何变化**：需要强拖影时，写“运动区域的形体沿指定方向被拉伸，内部颜色与轮廓相互融合，形成延展的曝光拖痕”，并按参考补充长度与细节损失程度；不要只写“高速、强烈模糊”，以免仍保留完整实体加模糊边缘。这里指成像中的拉伸，不是人体或物体真实结构变形；仅用于指定运动区域，不能误伤相对静止主体。极强残影可再锁定“原位置没有清晰核心”。
- **先选残影质感，再选形容词**：根据参考区分平滑融合、断续拖曳与重复曝光。平滑融合写“内部色彩连续融合、边缘柔顺渐隐”；断续拖曳写“拖痕局部中断、浓淡不均”；重复曝光仅在确有多个分离轮廓时描述。不要惯性叠加“断续、重影、粗粝”，也不要把平滑模糊写成均匀几何色带。照片的原生粗粝感与拖影的平滑质感可以并存；柔光、低反差仅在参考支持时使用，不为残影效果擅自替换光线或色调。
- **描述残影的透明与消融层次**：参考呈现平滑残影时，说明形体从较浓色影逐渐过渡为局部透明、可透出背景的拖痕，再在尾部渐隐；用细节融合至不可逐项辨认来限定终点。浓淡、宽窄与透底应自然变化，避免密集刷毛状细丝、碎屑化和厚重涂抹。若目标是连续拉伸，残影须从原有形体连续延展，中途不重新聚集成第二个可辨认的人形或完整物体；不要用“淡淡的人形副本”误触发重复曝光。只有参考或用户确实要求多个轮廓时才保留分离重影。
- **明确跨区域的方向关系**：交代主体残影与相邻背景拖影是同向、异向还是背景稳定；方向一致时明确共用的画面轴向，避免各区域随机发散。方向、幅度和背景作用范围均依参考，不固定向左、不固定半幅，也不为统一走势把原本稳定的背景强行拉伸。
- **复用表达框架而非固定特效**：按“作用区域 → 拉伸方向与形态 → 细节消失程度 → 透明叠加与尾部过渡 → 与其他区域的方向关系”组织必要信息。忠实反推时只写参考已有的效果；清晰原图上的创意长曝光须由用户要求。保留原有机位、姿态、比例、环境和色彩，不自动引入半脸分区、霓虹发光或赛博调色。不同生成结果用于判断可见问题；提示词和模型同时变化时，不据单次对比断言模型优劣。
- **保留必要类别边界**：若来源类别对任务重要，用一次简短描述锁定，例如“掠影来自两轮摩托车经过”，随后只描述曝光残影，不再展开车型、零件或骑姿。完全省略类别可能产生其他车辆或物体；用户接受整体效果不代表类别漂移成为默认规则。
- **保留不规则的曝光痕迹**：按参考描述近景与远景残影的尺度、裁切、遮挡和局部透底，允许内部细节完全消失。避免均匀平行条纹、重复实体加拖尾、烟雾和发光速度线；不要为表现近景速度而放入完整巨大的车辆。拖影方向和幅度依当前图判断，不固定成某个斜向或固定画幅比例。
- **局部修正保留整体关系**：用户认可构图后，强化模糊时保留取景距离、人物占比、姿态、背景结构与分区色彩。墙顶、栏杆等用其在画面中与头肩、边缘的相对位置描述，避免只用现实高度推断；分清低墙加通透围网与高实墙。姿态按头、肩、胸、手臂和脚的可见关系描述，避免无依据地增加挺腹、屈膝等动作。调整天空色相时保留暖色地面和深色主体的关系。

## B：C4D / Blender 三维产品渲染

按优先级提取并整合：

1. **渲染类型与视觉方向**：判断产品主视觉、工业设计展示、概念广告、写实棚拍渲染、抽象艺术装置或电商产品图；只有证据充分时才提及软件或渲染器，否则描述其视觉效果。
2. **摄像机与构图**：描述正面、侧面、四分之三、俯视、仰视、微距或轴线视角；判断广角张力、标准透视、长焦压缩或正交感；说明产品位置、占比、朝向、裁切、留白、对称、对角线及空间层级。
3. **产品几何结构**：先写整体轮廓、体块比例和设计语言，再写决定辨识度的曲面、折线、开孔、接缝、悬浮件、轮组、灯具或连接结构。明确部件的嵌套、连接、间距与遮挡，不虚构不可见结构。
4. **材质**：逐个对应主要部件描述材质及表面表现，如哑光金属、阳极氧化铝、喷砂塑料、橡胶、玻璃、碳纤维、半透明树脂或镜面镀层；写清粗糙度、反射强弱、透明度、纹理尺度、边缘倒角与磨损程度。
5. **灯光**：描述主光、辅光、轮廓光、顶光、背光或发光结构的方向、面积、软硬、颜色和强弱关系，以及高光形状、阴影落点、接触阴影与反射控制。明确高调白场、暗调棚景或彩色渐变光的主导逻辑。
6. **环境背景**：描述无缝影棚、渐变背景、反射地台、磨砂地面、雾化空间、几何装置或抽象数字场景；交代地面与背景衔接、环境反射、阴影承托、漂浮或落地状态，不添加不存在的道具。
7. **色彩与曝光**：总结产品主色、点缀色、背景色和灯光色；说明高光、中间调、暗部层次、对比度、饱和度、白平衡和是否存在高调、低调、剪影或局部溢光。
8. **物理渲染与景深**：描述基于物理的光照、全局照明、光线追踪、真实反射折射、环境遮蔽、柔和接触阴影、景深和运动模糊等可见效果。仅在明显存在时写体积雾、焦散、色散、辉光或镜头光晕。
9. **核心锁定与负面约束**：用一句话锁定 5–8 个最影响相似度的要素，如视角、产品比例、关键几何、材质组合、灯光结构、背景、主色和景深。随后限制结构增删、比例失真、曲面塌陷、接缝错位、材质塑料感、反射脏乱、落地物缺少接触阴影或悬浮物被强加落地阴影、过曝、噪点、锯齿、错误景深或无关文字 Logo 等最可能错误。

## C：活动 banner / 促销海报

当画面属于活动 banner 或促销海报时，先读取 [活动 banner 反推参考](references/activity-banner.md)，再组织一段可直接复制的提示词。默认忠实反推参考图：保留原图的产品类别、数量、排布、造型关系和活动语义；用户经营滑板车独立站、此前提供过滑板车图片，或参考图属于促销海报，都不代表本次要替换成滑板车。只有用户明确提出“替换成我的滑板车”等替换要求，并提供对应滑板车图片时，才把这些图片作为产品外观与结构依据，在保留原 banner 的主题、构图骨架和空间关系的前提下安排滑板车；滑板车车杆、轮组等专属描述只在此明确替换情形下使用。**画面干净是核心：先确定产品视觉重心和构图骨架，再描述镜头、角度与空间纵深，最后才写必要细节；不靠增加道具、灯点或风景来填充空间。干净不等于纯色或无纹理；参考图中的低对比背景肌理、材质纹理和承担构图/支撑功能的抽象结构都应保留。**明确相机高度、俯仰方向、透视感和产品可见面，并把镜头机位与产品自身朝向分开；交代前景、主体、背景的层次以及主体间的大小、距离、遮挡、接地和视线落点。活动图默认以参考图中的产品主体作为全局第一视觉重心，背景、文案和装饰退居辅助；前期提示词保持干净，只保留必要场景和构图引导，细碎装饰留给后期添加。用户要求忠实复刻复杂参考时保留关键构图与产品关系，但仍确保产品第一眼突出。简化时区分构图骨架与次要装饰：保留产品的悬浮/落地状态、角度穿插关系和环绕性主视觉结构，不擅自改成展示台或添加底座、线缆。若抽象带状结构在产品下方承托、从主体前后环绕或构成空间路径，要写明其连续走向、产品接触/承托关系、前后遮挡、半透明度和可见纹理，不能只描述成背景曲线。描述飘带前先判断活动场景；若飘带构成心形等主题符号，保留其形状语义，若无明确象征意义，再将其作为引导线指向产品。有人物与车辆同框时，核对人物在车内/车外、动作和遮挡；描述灯光时明确最亮点及其向周围衰减的层级，不添加参考中不存在的灯源或场景道具。若参考图有明显的山脊、起伏草地、道路或织物边缘等线形，描述其起点、延伸方向与视线落点，说明自然引导线如何汇向或框住产品，避免遮挡主体或把视线带出画外；不凭空添加箭头或装饰线。同时核对镜头透视与焦段感、承托结构是否完整入镜及其与产品的支撑/连接关系；有运动感时明确倾斜、摆动方向和轨迹，避免把秋千等结构误写成展示台。只有明确要求替换为滑板车时，才额外保证细长车杆完整、可辨，并与其后方背景形成足够明暗或色相对比。

## 输出自检

输出前在内部确认：已选 A、B 或 C；没有暴露分析过程；所有空间关系与可见证据一致；A 已保留原生拍摄感、自然动作与取景留白，面部无油亮或过度精修倾向，未靠添景和加重纹理制造真实感；速度型参考已分别描述主体与背景的拖影方向及清晰度损失，色彩已按区域和明暗层次判断，无相互冲突的清晰度要求；极强残影要求下已减少结构词重复、消除清晰核心，保留必要类别边界和已认可的构图色彩；C 已明确镜头高度/角度、主体朝向、前中后层次和纵深，保留参考图必要的结构与材质纹理，且没有为了营造纵深而添加无依据的装饰；没有重复描述；核心锁定与负面约束具有针对性；最终为一整段中文，A/B 通常约 800–1200 字，C 通常约 700–1000 字且不为凑字数添元素，可直接复制使用。

# 活动 banner / 促销海报：反推与提示词模板

## 使用边界

用于独立站首页横幅、促销 banner、节日活动图和产品活动海报的图片反推。画面以促销信息与产品主视觉为核心时，即使产品是 3D 渲染，也使用本模式。默认按参考图原有产品类别、数量、造型、排布与产品关系忠实反推；用户的店铺品类、之前提供过的产品图或历史偏好都不能单独构成替换要求。只有用户明确说要把参考图产品替换成自己的某款产品，并提供对应产品图片时，才用图片作为替换产品的结构依据；此时保留参考图的活动主题、构图骨架和空间关系，再按新产品的真实结构调整占位。没有明确替换指令时，提示词中不得擅自加入用户的滑板车或其他自有产品。

活动图默认以参考图中的产品为全画面的第一视觉重心：产品在位置、面积、清晰度和明暗对比上都要最突出，活动文案、场景和装饰只能辅助，不能与产品争夺注意力。前期提示词优先保持背景干净，只保留产品识别、必要的构图引导和少量点题元素；细碎节日装饰、纹理和周边道具留给后期添加。反推参考图时保留产品数量、主要排布和决定空间关系的构图骨架，例如产品悬浮/落地状态、倾斜与穿插关系，以及环绕产品的主视觉装置；简化时只删减次要装饰，不把构图骨架改成普通背景或展示台。除非用户明确要求，否则不添加参考图没有的圆台、底座、线缆或配件。产品仍须第一眼突出。若用户明确要求换成自有产品，则仅在该次提示词里描述替换产品的结构特征；滑板车细杆、轮组等专属规则也只在滑板车替换时启用。

简洁指画面元素克制，不是删掉构图骨架或让提示词信息不足。输出仍需交代清楚构图占位、产品或产品组之间的主次、必要的视觉引导线、文案层级、前中后景关系、材质细节、主光与补光关系、综合色彩和针对性负面约束；产品始终是全局视觉重心，环境和活动元素不得在面积、对比度或细节密度上压过产品。产品的悬浮/落地状态、倾斜穿插关系、环绕主体的主视觉装置等若决定画面结构，就要保留；可后期添加的碎细节不纳入前期提示词。

## 画面骨架与纵深（核心优先级）

保持画面干净是核心。按“视觉重心与留白 → 镜头角度 → 空间层次与纵深 → 必要细节”的顺序组织提示词，不要从装饰清单开始堆元素。先锁定产品组和文案区的位置、占比与主次，再描述相机从哪里看、产品朝向哪里，以及前景、主体、背景如何分层。明确产品之间的远近、大小、间距、遮挡、接地和朝向；用透视、尺度变化、错位、轮廓分离、接触阴影和少量引导线建立纵深，不要靠增加无依据的小道具、灯点、雾气或风景填满画面。干净不等于纯色或无纹理：保留参考图已有的低对比背景肌理、带状结构上的细纹、半透明材质和层次反射，控制其密度与对比度，使它们服务于产品承托和构图。背景只保留能解释活动主题、支撑产品或引导视线的必要元素；留白就是构图的一部分，不要擅自填满。忠实反推时保留参考图决定构图的关键结构，只有用户要求简化时才削减原图装饰。

## 反推优先级

1. **画幅、信息区与视觉引导**：判断横幅或海报比例、文案区、产品区、留白方向，以及主体的位置、大小、朝向和裁切。结合文案、活动主题和画面线索先判断海报的使用场景，再辨认装饰的作用。尤其是飘带：若它构成心形等可辨识的主题符号，应保留其轮廓、转折和包围主体的关系，写明它承载的情绪语义；若没有明确象征意义，再将飘带作为克制的视觉引导，描述起点、转向和落点，让视线导向产品。自然地形、道路等线形也需说明走向与视线落点；不凭空添加箭头，不让线条遮挡产品或把视线带出画外。先确认文案与产品主体是否争抢空间；不要把常见的“左文案、右产品”硬套到不同构图。
2. **产品辨识度**：先概括参考图中产品的整体轮廓、颜色、角度和比例，再保留少数可见的识别细节；明确产品组的主次、间距、遮挡与朝向。若用户明确要求替换为滑板车并提供车辆图，再额外关注细长立杆：保持车把到前叉/前轮方向的轮廓连续，杆后避免出现同色细线、强纹理或密集装饰，确保杆体与背景有清晰的明暗或色相分离。
3. **活动信息层级**：按画面证据描述主标题、优惠、日期、副标题和 CTA 的大小、位置、对齐与留白。只转写能辨认的文字；文字不清时描述其层级和占位，不猜拼写、品牌、金额或日期。
4. **背景与活动符号**：写清主背景的色彩、材质和大形状。简洁方向下，背景以一个低干扰基底为主，最多选一个有识别度的活动符号或道具作为点题；其余细节用于产品本身。只描述参考中确实出现的场景结构，不根据主题联想擅自添景；例如淘金主题不等于木质矿道、铁轨、灯笼或灯串，金色方块墙上的字样也不自动变成独立木牌。
5. **光源层级**：判断画面最亮点在哪里、它是什么光源、朝哪个方向照射，以及亮度如何向周围衰减。若洞口、灯具或发光部件是明确视觉焦点，就让它成为最亮处，周边墙面、人物、产品和地面逐级降低亮度；光晕限制在光源附近，不把局部亮口扩写为整片发亮。其他补光或轮廓光只在参考图可见时保留，并与主光协调。若图中没有单一强光，则忠实描述漫射或均匀光。若画面主体是滑板车，只在确有需要时用柔和边缘光保持车杆清楚；阴影、接触面和反射方向一致。
6. **色彩和细节**：用一组主背景色、产品本色和至多一个活动强调色概括画面；只有参考明确呈现多色时才保留丰富配色。把“有细节”落实为真实材质、接缝、轮胎、踏板、灯具、文字边缘或克制的局部反射，不添加无关小物件。
7. **反推约束**：用一句话锁定参考产品轮廓、产品/文案分区、背景复杂度、活动符号、主光方向和色彩关系。仅在用户明确要求替换为滑板车时，再把车杆清晰度纳入锁定。针对简洁方向补充负面约束：不增加重复产品和无关道具；不让繁密纹理、飘带或光效穿过产品关键轮廓；滑板车替换场景下还要避免元素穿过车杆；不堆叠多个强光、不同色温轮廓光、光束、光斑、雾、辉光或镜头光晕；不生成杂乱、拼写错误的文字，不改变产品结构或比例。

## 镜头、承托结构与运动

- **镜头透视**：明确相机的机位高度、平视/俯视/仰视、俯仰方向，以及画面能看到产品的正面、顶部或侧面到什么程度；将镜头机位与产品自身朝向分开描述。再判断广角、标准或长焦的视觉效果，观察近大远小、边缘拉伸和空间压缩；只描述画面支持的焦段感，不臆造精确毫米数。相机透视应与产品比例、主体位置和前后关系一致。
- **空间层次与纵深**：交代前景、产品主体和背景的空间顺序，以及产品之间的远近、大小变化、重叠/遮挡、地面接触与阴影关系。若是高机位或俯拍，说明可见的地面/顶部平面和主体朝向；若是低机位，说明主体与背景的高度关系。纵深优先由透视、尺度、错位、遮挡和接地关系建立，不额外添加景物来制造深度。
- **承托与连接**：先识别场景结构的实际功能，如秋千、吊台、地台、展示架或抽象带状装置；写清整体轮廓、支撑点、绳索/支架/带状结构如何延伸，以及产品是放置、悬浮、悬挂还是被其承托。若抽象的半透明带子从产品前后环绕并在下方托住产品，说明带子的连续路径、转折、前后遮挡、承托面和产品接触位置；保留其半透明/磨砂/透明观感、细密纹理、边缘高光和环境反射，不要把它降格成单纯背景曲线或不透明平台。参考中完整露出的结构要完整入镜，不要把秋千改成展示台，或凭空增加底座、线缆和连接件；产品接触位置与阴影应合理。
- **运动状态**：若画面表现运动，明确主体结构的倾斜、摆幅、运动方向和轨迹，确保绳索、飘带、叶片等动态线索彼此一致；产品仍需清晰稳定，不用随机拖影代替明确的运动姿态。
## 悬浮、材质与带状元素

- **保留悬浮与裁切**：分别判断整组、容器和配件的空间状态。参考为悬浮构图时，不补地面、台面、地平线或地面投影；用重叠、尺度、角度和物件之间有依据的遮蔽表达纵深。保留参考的底边裁切与露出比例，不能为了完整展示而改变占位。修正人物比例或产品大小时，也不能牺牲原有俯视机位和空间结构。
- **形态与连接先于装饰**：辨明容器是否舒展、开口是否宽松、布面是平缓折痕还是收紧褶皱。描述袋子、织带等时，先确认带子属于物件自身还是独立装饰；保留可见的前后部件、数量、连接归属和遮挡，不能将提带拆成飘带，或忽略被部分遮挡的后侧提带。产品贴附、叠合或局部悬浮的关系也应保留。数量和连接方式按当前参考判断，不把本例的两条提带固定套用到其他图。
- **简洁画面的材质差异**：将细节集中在真实材质与接合处。区分相邻材料的纹理粗细、织纹密度、厚度、柔韧度及哑光/柔光表现，例如帆布袋与细密织带不能使用同一种粗糙纹理；保留带面翻转的正反面明暗和克制的文字工艺。材质不确定时描述可见表现，不臆断纤维成分；不靠加粗纹理或增加皱褶表现质感。
- **织带、提带、飘带的走势**：以自然舒展、宽缓流动、服务产品构图为目标。提示词写清所属关系、必要连接、前后层次和总体延伸方向即可，通常不逐段指定转折、角度或回接路线。结构性提带保留连续连接；自由飘带保留引导作用；心形等主题符号保留其语义轮廓。避免机械对称、过度收紧、纠缠、夸张回环或遮挡产品；不把某一种 U 形、左右不对称或具体弯曲路径设成所有图片的硬规则。
- **人物和环境的权重**：产品保持全场第一视觉重点。若人物是微缩尺度参照，保留其相对体量与原有活动，不放大为近景主角，也不擅自添加触碰、围绕产品的互动或宠物；不将固定人物高度比例或统一虚化套用于所有参考。

## 多产品/多车辆的摆放与层次

先判断画面是在做“车型促销陈列”还是“突出主车的场景组合”，再选择排布方式；不要把所有多车画面都写成等距并排。车型促销或清仓画面可采用同一地面上的横向阵列，强调选择丰富；需要主视觉或户外动势时，优先采用前后错层和明确主次。

- **主次与深度**：两辆车时，让一辆更靠近镜头、面积更大，另一辆退后并向侧边错开，形成自然的斜向双车组；三辆车时，可用“中间/一侧主车更大更靠前、两侧副车更小并略退后”的浅三角或弧线排布。副车的尺寸、把手高度和横向位置要有变化，避免三根细杆齐刷刷同高成一排，或彼此重叠成一束。只有参考本身是整齐商品陈列时，才保留近似同尺度、同纵深的平排。
- **滑板车轮廓**：车把、细长立杆、前叉、踏板和前后轮是连续识别轮廓。摆放时优先错开各车的立杆和车把，让每辆车的杆体从车把到前轮区域都能独立读出；踏板不要互相压住，前后轮不要重叠到难以判断车辆归属。允许局部遮挡来建立前后关系，但不能遮掉主车的车把、立杆关键段、踏板或轮组。
- **单车轮廓**：多辆单车可用前后错层或轻微内外转向形成组合，但需分别保留车轮圆形、前叉、车架三角结构、车把和鞍座的可读性。避免前轮互相压叠、车架线条混成一团，或让后车的车把/鞍座误接到前车车架上；主车可用更靠前、更大的车轮建立空间层次，副车退后但仍完整可辨。
- **朝向和透视**：把“镜头机位”与“车身朝向”分开描述：整组车共用同一镜头透视，但每辆车的水平转角可以不同。只写“朝向协调”或“侧前方三分之四视角”太含糊，模型容易把所有车画成同一方向的近侧视平行车列；需分别说明哪辆车以前轮朝向镜头、哪辆更侧向、车头朝向画面哪一侧，以及踏板/后轮向哪里退远。做主视觉组合时，让主车以清楚的前侧三分之四角度突出，副车的车头角度轻微朝向主车或组内视觉中心，避免整组车头都指向画外或左侧文案区；车型促销陈列才适合同向整齐排列。车把转角、前叉和前轮方向必须符合真实转向关系，车杆与车身透视自然。避免超广角导致近处车轮异常膨大、车杆倾斜或车架比例变形。
- **白底产品图的角度用途**：相近角度的白底图用于锁定每款车的身份、结构、比例和颜色，不代表场景里每辆车都必须复制相同朝向。除非用户要求保留原角度，否则提示词应单独安排每辆车相对镜头的转向；只改变车辆在场景中的摆向，不镜像或改造产品结构。
- **接地与留白**：落地车辆的轮胎、脚撑与地面/台面关系要可信，接触阴影和地面透视一致；如果参考中产品悬浮或依托特殊结构，则准确保留该状态及承托关系。车组整体需与文案区分开，车把上方和轮组之间保留足够间隔，不让文字、飘带或道具穿过关键轮廓；除非参考明确裁切，否则完整露出车辆外轮廓。

当参考图确有多辆车，或用户明确要求用多辆自有车辆替换时，提示词要把“车辆数量、主次、前后关系、左右位置、大小变化、每辆车的朝向与转角、间距、遮挡、接地状态”说具体；滑板车还要说明车把/前轮朝向和踏板/后轮退向。区分全组共用的镜头机位与各车自身的摆向，不要只写“几辆车整齐展示”“采用三分之四视角”或“产品组合摆放”。若参考主体不是车辆，则按其原有产品类别和结构关系描述，不套入车辆陈列规则。

## 一段提示词的覆盖项

将下列信息自然整合进同一段，不必写成分项清单：活动使用场景与主题语义；画幅、主体/文案区的位置和占比；飘带等装饰是主题符号还是视线引导，以及其路径、转折和落点；参考图产品主体及配件的数量、朝向、比例、相互距离和遮挡；可见材质与关键结构；前景、主体、中景、远景的层次，以及远景山脊、前景地形/道路/织物等如何形成视觉引导并指向主体；镜头角度与焦段透视感；承托结构的完整轮廓、连接方式和产品接触关系；运动方向、倾斜与轨迹；文案内容和排版层级；人物与主体的内外位置、动作及遮挡关系；主光方向、软硬、色温、最亮点与亮度衰减及阴影关系；主色与点缀色；产品轮廓、留白、光线和装饰控制等负面约束。仅当用户明确提出替换且提供产品图时，才把替换产品的外观与结构写入提示词；滑板车车杆和车辆朝向等规则仅在此时按需启用。不可见内容不猜测，忠实复刻时不为简洁而删除参考图中的关键元素。

## 关系与光线的校准例

有人物与车辆同框时，明确人物是在车内、车外、车上还是车旁，身体是否探出、哪只手抬起，以及车窗、车门和车身的遮挡位置；不能把“从车内探身”改写成“站在入口旁”，也不能把单臂动作扩写成双手举起。

遇到有明确发光入口的场景，按画面锁定唯一最亮的视觉锚点及亮度递减关系：入口最亮，周围建筑、人物、车辆和地面逐级变暗；除非参考里可见，不添加灯串、沿墙灯、额外聚光灯或大面积泛光。招牌按真实附着关系描述，例如字样直接安装在方块墙面上时，不改成独立木牌或门头。

## 可复制提示词模板
制作一张用于【独立站首页横幅/活动页/促销海报】的【画幅比例】【活动主题】商业主视觉，整体风格【从参考图归纳的视觉气质】，默认忠实保留参考图中的产品类别、数量、外观、姿态、排布和相互关系；只有在用户明确要求替换产品并提供对应产品图片时，才把主体替换为指定产品，并以所给图片锁定其结构、比例、颜色和可辨识细节，同时保留参考图的活动语义与构图骨架。画面以【参考图中的产品主体或产品组合】作为全局第一视觉重心，在面积、位置、清晰度和明暗对比上最突出；按参考图明确产品之间的主次、左右位置、前后层次、大小变化、朝向、间距、遮挡和悬浮/落地状态，不擅自改为常见陈列角度或添加参考图没有的支撑物；通过前景/主体/背景的相对尺度、错位和遮挡建立纵深；落地时保留接触阴影，悬浮时保留无地面的空间与原有裁切，不用额外道具填满空间。先明确相机的【机位高度、平视/俯视/仰视、俯仰方向、可见的产品表面】，并与产品自身朝向分开描述；再写【广角/标准/长焦透视感】，依据参考图描述近大远小与空间压缩，不编造精确焦段；若存在承托结构、悬挂装置或运动状态，准确描述完整轮廓、连接点、产品与结构的接触关系，以及明确的倾斜方向和运动轨迹；若半透明带状结构从产品前后环绕并在下方承托产品，补充其连续路径、前后遮挡、承托面、半透明材质和表面细纹，不把它简化成背景曲线或纯色平台。先结合活动文案与场景判断飘带、地形、道路或其他线形元素的语义：若其构成心形等主题符号，保留完整轮廓及表达的情绪；若带子属于物件自身，保留其前后部件和连接归属；织带、提带与飘带以自然舒展的整体走势为主，概括方向和前后层次即可，不逐段规定弯折。若只是视觉引导，使视线自然回到产品，不遮挡主体。画面干净是核心，背景保持低干扰；保留参考图已有的渐变、低对比肌理和材质纹理，不默认改成纯色，也不凭空增加景物；只保留支撑活动主题和产品关系所必需的场景、一个主要活动符号与有效的前中后景层次；留白不擅自填满，不用额外装饰制造纵深；为【标题、优惠信息、日期、CTA】保留清楚的文案区，准确描述其位置、对齐和层级，文字不清时只留占位，不猜写内容。产品细节聚焦于【少数清楚可见的材质和识别结构】，不以额外道具填满画面。按参考图锁定【最亮区域/主要光源、方向、色温和亮度衰减；若无明确强光则说明均匀或漫射光】，让最亮点有清晰主次，其他区域逐级过渡；只保留有画面依据的补光与反射，确保阴影方向和接触关系一致。综合色彩以【背景主色、产品本色、少量强调色】为主，确保产品始终最醒目。若本次明确要求替换为滑板车且提供了车辆图片，再补充车辆数量与主次、各自车头朝向和转角、车轮/踏板退远方向、车把至前叉的车杆轮廓连续清晰、车轮和踏板不互相遮挡等专属要求；未明确要求滑板车替换时，不提及或加入滑板车。避免复杂背景、无关道具、过密纹理、抢眼装饰、相互冲突的多方向强光、过曝光斑、无依据的光束/辉光/镜头光晕、杂乱文字、产品比例或结构改变，以及任何与参考图空间关系不一致的内容。
